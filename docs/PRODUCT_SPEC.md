# Product Spec — MathTutor (4th Grade)

## Audience

4th-grade students doing short daily practice; parents/teachers reviewing progress.

## Core loop

1. Student opens Today view → sees warm-up (5 questions).
2. Answers with large touch targets, instant friendly feedback.
3. Progress bar + badges; per-skill mastery updates behind the scenes.
4. Next session adapts: weakest skills resurface (spaced repetition).

## Non-goals (v1)

No accounts beyond a simple profile, no multiplayer, no chat tutor.

## UX principles

Playful but clean; big type; one question per screen; never punish wrong answers — explain and retry a variant.
