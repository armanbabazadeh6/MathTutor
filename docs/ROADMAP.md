# Roadmap (8 phases)

1. **Foundation scaffold** (this task) — Next.js shell, design tokens, taxonomy, docs.
2. **Math engine** — question generators + answer checking per skill.
3. **Student player** — Today view, one-question flow, feedback, progress bar.
4. **Persistence** — DB migrations, profiles, attempts, mastery updates.
5. **Adaptivity** — spaced-repetition picker over weakest skills.
6. **Admin dashboard** — per-skill mastery view for parents/teachers.
7. **Polish** — animations, sounds, badges, offline tolerance.
8. **Launch** — Vercel deploy, seed content QA, analytics.
